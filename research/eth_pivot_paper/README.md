# ETH Pivot Reversal BUY paper test

This is a forward paper record of TradingView's built-in Pivot Reversal strategy, BUY side, on Exness ETHUSDm, from 2026-11-12. It was started after the 2026-11-12 audit found this strategy supported on both BTC and ETH. The rules are in [PROTOCOL.md](PROTOCOL.md), and `python src/paper.py` updates `ledger/`.
